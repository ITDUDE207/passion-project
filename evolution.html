Evolution Of HTTP


Otherwise known as The HyperText Transfer Protocol

It all started in 1989, when Tim Berners-Lee wrote a proposal to build a hypertext systen over the internet.
At first it was called Mesh but over the years we have come to call it the World Wide Web or WWW. Built over the existing TCP and IP protocols, it consisted of four blocks:
1: A textual format to represent hypertext documents, the HyperText Markup Language (HTML).
2: the protocol to send the documents to the client: HTTP
3: A client to display (and edit) these documents, the first web browser called the WorldWideWeb.
and
4: A server to give access to the document, an early version of httpd.
