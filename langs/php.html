Understanding PHP: A Beginner's Guide

This page explains what PHP is, what it does, and how it works—written entirely in standard HTML with no CSS styling.

1. What is PHP?

PHP stands for Hypertext Preprocessor. It is an open-source, server-side scripting language designed specifically for web development. Unlike standard HTML, which is static, PHP allows developers to create dynamic, interactive websites.

2. What Does "Server-Side" Mean?

To understand what PHP does, you must understand where it runs. Web technologies generally fall into two categories:

  • Client-Side (Frontend): HTML, CSS, and JavaScript run directly inside the user's web browser (Chrome, Safari, Firefox). The user can see this code.
  • Server-Side (Backend): PHP runs on the web server hosting the website. The user never sees the actual PHP code; they only see the HTML result generated by it.

3. What Does PHP Actually Do?

PHP handles the logic, data processing, and behind-the-scenes work of a website. Here are its main functions:

  • Generates Dynamic Page Content: PHP can change page content based on who is logged in, the time of day, or user actions.
  • Interacts with Databases: PHP connects websites to databases (like MySQL) to save, retrieve, update, or delete information (e.g., user profiles, blog posts, product listings).
  • Handles Web Forms: PHP collects data submitted through HTML forms, validates it, and processes it (e.g., sending an email or creating a new user account).
  • Manages Sessions and Cookies: PHP tracks user state across different pages, which keeps you logged into a website as you click around.
  • Controls User Access: PHP can restrict users from accessing certain pages unless they are authorised or logged in.

4. How PHP Works (The Visual Flow)

When a user visits a PHP website, the following steps happen instantly:

  1. The user's browser requests a page (e.g., index.php) from the server.
  2. The server detects the .php extension and passes the file to the PHP engine.
  3. The PHP engine executes the code, talks to a database if needed, and builds a standard HTML page.
  4. The server sends that clean HTML page back to the user's browser.
  5. The browser renders the HTML so the user can read it.

5. A Basic PHP Code Example

Below is an example of what PHP code looks like. It is wrapped in special tags: <?php ... ?>

<?php
// This is a PHP comment

$name = "Visitor";
echo "Hello, " . $name . "! Welcome to our website.";

// The output sent to the browser will simply be: 
// Hello, Visitor! Welcome to our website.
?>

If you view the source code of this page in your browser, you would only see the final text, never the original PHP variables or code structure.
